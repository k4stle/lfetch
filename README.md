# lfetch
A simple fetching tool for linux distributions

## why?
Fastfetch is bloated and takes too long to run, so I made this for linux. It works the same as the BSD version (bfetch) where everything is easy to understand and add to.

## installing
To install lfetch, make sure you have a C compiler then run the following:

```
gcc main.c -o lfetch
```
then
```
./lfetch
```
